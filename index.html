Apa itu BukuStok?

Aplikasi berbasis web untuk membantu UMKM mencatat stok dan penjualan.

Ada paket gratis?

Ya.

Ada multi outlet?

Ya, sesuai paket.

Apakah BukuStok memiliki fitur kasir atau POS?

Ya. Modul POS / Kasir membantu memilih produk, membuat transaksi, mencatat pembayaran, memperbarui stok, dan mencetak struk.
